## Checked and OK
- RevenueCat only in `RevenueCatBackend.swift`; key only from Info.plist/xcconfig; Release accepts only `appl_` keys; unit tests never configure the SDK (`XCTestConfigurationFilePath` guard); anonymous ID, no `logIn`; Release log level `.error`; automatic device-identifier collection off.
- `CustomerRules`: lifetime wins; an ended period never counts; trial from `periodType`; a renewing plan beside lifetime is kept (I2 warning); trial once per subscription group.
- Purchase: `.purchased` only when `pro` is active (`.notActive` otherwise); pending and cancelled handled; "plan not available" re-reads plans past the cache and falls back to "Plans aren't available right now" when none is left; errors logged as codes only.
- Trial length from the store's intro offer everywhere (review I-1 fixed): paywall, timeline, reminder, Today banner.
- StageRecaps: calendar-day maths (`ProgramCalendar.days`, DST-safe); pauses apply only after their `after` date; card ≤ 7 program days, one per round + stage, never stacked with Welcome back / Pick up / trial card; free plan never names a stop past the free leg (`route`), other places show reached stops only; stop ids unique across the 5 journeys (journeys.json, 30 ids); `restartProgram` clears pauses; `DataEraser` clears `programPauses` and `stageRecapSeen`, and every other key the app writes except M9.
- SwiftData: SchemaV1 untouched since 2a957e1, V2 + lightweight stage, `cloudKitDatabase: .none`, all contexts on the main actor, workout save throws instead of swallowing.
- `ForEach` identity in the new views: result tiles (unique enum), stage strips (stop ids), Journey "Your 12 weeks" (stage number), week bars and weekly notes (`weekStart`).
- Debug/Release: every `App/Debug` file and every `-ScreenshotMode` reference sits in `#if DEBUG`; `en-US.json` fixtures and `.storekit` excluded from Release.
- Concurrency: no `Task.detached`, no timers, no `Task {}` in a model `init`; `nonisolated(unsafe)` only for observer tokens and `UnitPreferences.current` (written on the main actor).
