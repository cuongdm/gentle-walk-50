# Gentle Walk 50+ (tên làm việc)

App iPhone/iPad dẫn đi bộ trong nhà, động tác ghế và giãn cơ bằng giọng cho phụ nữ Mỹ 50–64 mới tập. Kế hoạch hiện hành: `docs/plans/2026-09-29-mvp.md`. Việc cần làm: `docs/todo.md`.

## Quy ước dự án (manh-skill — đọc trước khi làm bất cứ gì)
- Step 0 of every task: read `app-context.md` (product truth) and the current plan in `docs/plans/`.
- Deployment target: iOS 18.0 (iPhone + iPad), Xcode 27 / SDK 27 — do not propose APIs newer than iOS 18 (e.g. `alert(item:)`, `reorderable()`, toolbar overflow APIs); flag it if unavoidable. `@State` is a macro in SDK 27: on "used before being initialized" read `swiftui-whats-new-27/references/state-macro.md`, never reorder assignments.
- Project is generated by XcodeGen: edit `project.yml`, run `xcodegen generate`; never commit `GentleWalk.xcodeproj`. Signing lives in `Config/Local.xcconfig` (git-ignored).
- Pure product logic goes in `Packages/GentleWalkCore` (Foundation only, `swift test`); Apple frameworks stay in the `GentleWalk` app target.
- Owner-facing text (reports, checklists, questions) in Vietnamese; code, comments and commit messages in English.

## Kiến trúc & UI
- SwiftUI first: `@Observable` `@MainActor` models with `Equatable` property types; one `struct: View` per section with narrow inputs; no work in `init` (swiftui-specialist `structure.md`, `dataflow.md`).
- `ForEach` / `List` identity: a stable stored id (`Identifiable`); never indices, `\.self` on structs, or ids minted in `body`; rows unary.
- Navigation: `TabView` (Today, Journey, Progress, Me), one `NavigationStack` per tab + one `navigationDestination(for:)` per type; onboarding, players and paywall via `fullScreenCover(item:)`; `sheet(item:)` for optional data.
- No hard-coded screen widths: never `UIScreen.main`; use layout containers, `ViewThatFits`, text styles. Body text ≥ 17 pt, touch targets ≥ 56 pt, contrast ≥ 4.5:1 (design spec).
- Data: SwiftData with `VersionedSchema` + `SchemaMigrationPlan`; never delete an old schema version; `cloudKitDatabase: .none` (health data never goes to iCloud).
- Workout audio is one `AVMutableComposition` played by one `AVPlayer` (voice, bells, music + audio mix ducking). Never play silent audio to keep the app alive (2.5.4).
- Content (exercises, journeys, voice lines, notification phrases) is bundled JSON in `App/Resources/Content/`; check it with `ContentValidator`.

## Ngôn ngữ (String Catalog)
- All user-facing text goes through `Localizable.xcstrings` / `InfoPlist.xcstrings`; `LocalizedStringResource` for non-literal text; interpolation, never `+`; format styles, never `dateFormat` literals; distance with `Measurement<UnitLength>`; `bundle: #bundle` inside packages.
- Locales: en-US; every new string is translated in every locale before a task is DONE.
- Copy follows `app-context.md` Tone & copy rules; run `python3 tools/lint/copy_lint.py` (banned words, medical claims, other platform names) → `0 findings`.

## Tuân thủ App Review / Play
- Paywall trio on every purchase screen: Restore control (`AppStore.sync()`), Terms of Use + Privacy Policy links, billed price the most prominent price; trial terms and auto-renewal visible; "Maybe later" always visible; no countdowns or struck-through prices.
- Entitlement truth: `Transaction.currentEntitlements` + a `Transaction.updates` listener; StoreKit 2 direct, no RevenueCat. Products: `com.kmd.gentlewalk.pro.yearly`, `.pro.monthly`, `.pro.lifetime`.
- Purpose strings: one `NS…UsageDescription` per permission actually used (Health share/update, Motion, Location When In Use), concrete purpose, localized; `PrivacyInfo.xcprivacy` kept in sync (UserDefaults CA92.1).
- Permissions are requested at the moment of need, never at launch: Health and notifications after the first workout (S16), location in Outdoor prep (S10b), motion when "Held to my chest" is chosen.
- Background modes only `audio` (spoken guidance) and `location` (outdoor route); entitlements only HealthKit. No other platform names in strings or metadata; no prices or invented numbers in copy; no medical claims (1.4.1).
- Review prompts only through `ReviewPromptPolicy`, never from a button (5.6.1).

## Chụp màn hình / test hooks
- Single capture hook: launch argument `-ScreenshotMode <state>` under `#if DEBUG`, seeding `App/Debug/Fixtures/en-US.json` and the named screen state (list in the plan's Localization section). Never add a second convention; revert other temporary hooks before a stage ends.
- Tests: Swift Testing; `@Suite(.serialized)` for suites sharing a store, UserDefaults or a `SKTestSession`; in-memory `ModelContainer` per test; `App/GentleWalk.storekit` for StoreKit tests; dates, time zones and calendars injected.
